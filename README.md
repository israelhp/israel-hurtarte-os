# ISRAEL HURTARTE.OS

Interactive desktop-style portfolio of Israel Hurtarte (Full Stack Developer, Guatemala). Next.js · React · TypeScript · Tailwind · Zustand · Vercel.

```bash
npm install
npm run dev          # http://localhost:3000
npm run check        # typecheck + lint + unit tests + production build
npm run test:e2e     # Playwright (after npm run build)
```
