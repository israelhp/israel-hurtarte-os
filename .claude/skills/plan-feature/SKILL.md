# Plan feature

1. Copy docs/specs/_template to docs/specs/<ID>/.
2. Fill spec.md (goal, scope, acceptance criteria, content status, i18n, a11y), design-reference.md (prototype lines), plan.md (modules, state, risks), tasks.md.
3. Add the task to docs/tasks/BACKLOG.md as Ready. Ask the owner about any real decision.
